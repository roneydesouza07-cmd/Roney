# Brick — Gestão de Revenda

App (PWA) para controlar o brick: produtos comprados, anunciados e vendidos, com
investimento, faturamento, lucro, margem, ROI, caixa e relatórios calculados automaticamente.

- Funciona offline e pode ser instalado na tela inicial do celular.
- Os dados ficam salvos no próprio aparelho (use **Caixa → Exportar backup** de vez em quando).

## Publicar (GitHub Pages)
Settings → Pages → *Deploy from a branch* → escolha a branch e a pasta `/ (root)`.
Depois abra o link no celular e use "Adicionar à tela inicial".
